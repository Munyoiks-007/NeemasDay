HOW TO RUN
1. Open index.html in your browser (double-click it). No install, no server needed.
   Optional: in this folder run  python3 -m http.server 8000  and open http://localhost:8000

HOW TO CUSTOMISE
1. Drop her photos into the images folder.
2. Add your video file next to index.html, named "our-video.mp4" (or change the video src in content.js).
3. Open content.js and change the name, dates, text, notes and letter.
4. Refresh the browser.
5. Add or rename songs in the music folder and update the music list in content.js. Use the "Next song" button to switch tracks.

PICTURES FROM YOUR PHONE
Resize big photos to about 1600px wide first so the page loads quickly.
